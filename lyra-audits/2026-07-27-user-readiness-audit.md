## Cross-cutting defect patterns

- Built-tested-green-but-never-wired (the estate's signature defect, 8 verticals): research_analyst agent endpoint (V5), fundamentals+intelligence workers write to unread tables (V9), USAspending gov-awards ingestion cron-warmed but unsurfaced (V10), paper-trading.ts ~90% dead incl. the automation-readiness gate (V13), portfolio DELETE only reachable via chat undo (V4), AI system-card API-only with dead markdown renderer (V11), native push plugin bundled with zero JS callers (V14), dead AiInsightStep switch case (V7).
- Fabricated/demo data presented as real with no disclosure (trust breach on a research-first tool): PRNG-synthesized 6h score history shown as intraday (V3), demo fundamentals/intelligence always rendered regardless of worker output (V9), fabricated news as 'Live' with real firm attributions + hardcoded hype scores as 'computed' (V10), tour $100k mock vs $5k real default (V13).
- Thin/absent test assertions on safety-critical logic - the dominant driver of low coverage sub-scores across nearly every vertical: display module live-signals.ts untested (V1), RLS fence untested (V2, V8), shell layout/nav/freshness untested (V3), handleFinish + onboarding navigation untested (V7), findings projection + graph builder untested (V10), validateGenUIView unpinned (V11), quality gates have no red-proof self-tests (V15), landing render untested (V16), add-flow components untested (V4).
- Dead/inert UI controls that look interactive but do nothing: fake 'Search: NVDA' header box (V3), Custom frequency/scope dropdowns + split-brain quiet hours in AccountMenu (V6), watch-rule threshold fields never rendered (V4), Solo alert choices forced to 'muted' (V7), Solo upgrade CTA dark by default (V12).
- Serverless in-memory state assumed durable / cross-instance (financial-DoS and rate-limit controls that degrade to per-lambda on Vercel): hosted-budget ceiling decorative for brief/explain routes (V5), AI-ops metrics read an in-memory store the prod writer never fills (V5), Telegram rate-limit + dedupe per cold instance (V6), anon abuse-damping degrades per-instance when Upstash is down (V12).
- Two-code-path divergence producing inconsistent numbers for the same concept: TS-daily vs Python-hourly scores and differing RSI seeding (V1), Solo P/L drops brokerage fees the Python engine includes (V4), 'Vol' chip means ratio in live vs 0-100 score in demo (V10), session-scoped equity plotted against 30d daily benchmark on a shared axis (V13).
- Solo/demo indistinguishability and error-path fallback leakage: solo and demo share generatedFrom:'demo' so surfaces re-derive mode client-side and a configured-but-erroring deploy can render the seeded sample book to a real user (V2); Solo overlay hardcodes riskState='neutral', suppressing the headline protect-capital exits (V4).
- Schema/gate blind spots: live schema-drift probe not in blocking CI + migrations applied by hand (V2), drift gate checks existence not type/nullability/defaults and only guards literal user_id columns (V15).
- Sub-44px touch targets recurring across surfaces (V1,V3,V4,V5,V8,V13,V16) - a genuine a11y note but consistently tempered by Lyra's intentional ultra-compact density doctrine, so correctly kept at P3.
