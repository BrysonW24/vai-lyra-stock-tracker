# P8 - Onboarding restyle (2026-08-02)

Token convergence for the onboarding package onto TOKENS.md v1.0.0 + PATTERNS.md:
`src/app/onboarding/page.tsx` + all 21 files in `src/components/onboarding/`. This package
carried the worst three-way dialect mix in the app (raw hex, `bg-white/[...]` glass, and one
stray LIGHT-mode surface); all three now converge on the token vocabulary, matched against the
already-converged activation sibling. Zero raw hex, zero white/black-opacity fills, and zero
non-token radii remain in P8-owned classnames (remaining literals are the documented artistic /
functional allowances listed below). Verified: `node lyra-ux/check-tokens.mjs` OK,
`npx tsc --noEmit` clean, `npx next lint` clean for both owned dirs, targeted
`npx vitest run` green (onboarding, onboarding-save, demo-carryover - 29 tests). No exports,
props, behaviour, a11y semantics, animation names, or provenance/honesty copy changed.

## What changed

- **Canonical hexes -> Tailwind token names** across every file (`#eef3f8` -> `ink`,
  `#8190a0` -> `ink-3`, `#263241` -> `line-strong`, `#0d141c` -> `panel`, `#f3a33a` ->
  `accent`, `#8aa2ff` -> `pending`, `#60a5fa` -> `blue-focus`, etc.), following the P1/P2
  nearest-token ruling table for legacy off-palette hexes: dim greys `#5d6b79 #6f7d8a` ->
  `ink-dim`, `#cdd8e3` -> `ink-title` (data) / `ink-2` (inactive ChoiceChips, per PATTERNS),
  green borders `#1d7f55 #1d4f3a` -> `positive/40|30`, red sets `#7a2230 #7f1d1d` +
  `#2a1115 #2b1214` -> `negative/40` + `negative/10`, dark ambers `#23180b #1a130a #231a08` ->
  `accent-tint/80|60` + `accent-tint`, `#5a4a1a` -> `accent-border/60`, violet tints
  `#101a2e #13203a` -> `blue-tint(/80)`, input wells `#080a0d #0b1119` -> `well`,
  dropdown border `#2c3a4a` -> `line-strong`, suggestion highlight `#151c25` -> `blue-tint`
  (selection semantics, matches the app's blue ::selection), hover fills `#101720 #103626` ->
  `hover:border-line-hair` / `hover:bg-positive/20` / `hover:bg-accent-tint`.
- **Gradient CTA convergence**: every step's primary CTA swapped from the legacy tri-colour
  `from-[#3b5bdb] via-[#43d18b] to-[#f3a33a]` + dark label to THE token CTA -
  `rounded-cell bg-[image:var(--lyra-cta-gradient)] text-white min-h-[44px]` - identical to
  the activation sibling (CalibrationShell/ActivationSequence), one per view. The
  TickerLookupInput "Add" button (a second gradient in the same view) became the PATTERNS
  primary button (`bg-blue text-white`), restoring the ONE-gradient-CTA rule on the
  watchlist/portfolio steps. Decorative tri-gradients that are not CTAs (WelcomeHero icon
  tiles + glow, OnboardingShell/beat progress bars) became token-named gradients
  (`from-blue-deep via-positive to-accent`).
- **The light-mode stray is gone**: DemoCarryoverConfirm was a full warm-paper surface
  (`bg-[#F7F6F2]`, white glass card, `#0E1E3A`/`#5A6B82` text, light-blue heros). Now
  `bg-ground text-ink`, `.terminal-panel rounded-panel` summary card, `from-blue to-blue-info`
  headline gradient + icon tiles, token error block, token CTA + ghost button. Copy verbatim.
- **White/opacity dialect migrated** (TickerConstellation, AlertPreferencePanel ChannelCard,
  WelcomeHero cards): `border-white/10` -> `border-line`, `bg-white/[0.05|0.06]` fills ->
  `bg-panel` / `bg-well`, `bg-[#0c1118]/90` -> `bg-panel-deep/90`, `via-white/25` hairlines ->
  `via-ink/25`, `ring-white/40` -> `ring-ink/20`, label chip bg `rgba(13,17,23,0.55)` ->
  `bg-panel-deep/55`.
- **Bespoke visuals now consume tokens** while keeping their art:
  - TickerConstellation: sector colours are token-driven end to end - THREE sprite colours
    resolve CSS variables at runtime (`getComputedStyle`), HTML chips/fallback grid use
    Tailwind classes. Mapping: Semiconductors -> `blue-focus`, Mega-cap -> `accent`,
    Cloud -> `positive`, Cybersecurity (`#a78bfa`) -> `pending`, AI infra (`#4fd1d9`) ->
    `blue-info`; web lines `0x5a7da6` -> resolved `ink-3`.
  - GlassRadarOrb / MomentumPulse: SVG gradient stops resolve `var(--lyra-*)` via
    `style.stopColor`; static fills/strokes use `fill-*`/`stroke-*` token utilities.
  - GlassPortfolioStack: per-card colours are `var(--lyra-*)` strings applied via style
    props (SVG presentation attributes cannot carry `var()`).
- **Radius convergence**: `rounded-md`/`rounded-lg` cells, inputs, chips-with-tap-targets and
  buttons -> `rounded-cell`; `rounded-xl`/`rounded-2xl` panels, step cards, icon heros ->
  `rounded-panel`; status pills stay `rounded-full`.
- **44px mobile targets** (this flow is mobile-first): all primary CTAs and the
  Operator-profile Next button carry `min-h-[44px]`; OnboardingShell back button `h-9 w-9` ->
  `h-11 w-11` (matches CalibrationShell); footer Back and the AiInsightStep skip row get
  `min-h-[44px]`; the ticker lookup input + Add button `h-9` -> `h-11`; remove-X buttons use
  the `-m-2 p-2` hit-area idiom (no layout shift).
- **tabular-nums** added on the dense digit surfaces (holding cost/value rows, alert-price
  previews, money inputs, snapshot metric lines, completeness %), per PATTERNS.
- **Animations untouched**: `radarSweepSpin`, `orbitSpinFwd/Rev`, `pulseCore`, `pulseScanX`,
  `creatureFloat`, `animate-pulse`, `animate-spin` all keep their names, durations and
  wiring; keyframes stay in globals.css.

## Deliberate allowances (documented in-code)

- Token-valued rgba glow shadows (`rgba(67,209,139,...)` = positive, `rgba(138,162,255,...)`
  = pending, `rgba(30,99,255,...)` = blue, `rgba(59,91,219,...)` = blue-deep) and black
  drop shadows - the exact dialect the converged activation package uses.
- TickerConstellation's white radial glow texture: functionally required (sprite material
  colour multiplies the texture; a white core is what lets the token tint render).
- GlassRadarOrb: solid white logo tile (favicons need a neutral ground - founder-noted
  legibility), the deterministic per-symbol `hsl()` monogram fallback, and the 6% white glass
  rim.
- MomentumPulse: two lightened highlight stops (`#cfe3ff` scan tip, `#ffce8a` "now" node) -
  artistic highlights of blue-focus/accent under the glass-visual allowance.
- MarketUniverseSelector: the sector-grid sweep interpolates numeric RGB at runtime; its
  anchor stops are the token values of blue-focus/positive/accent with two artistic
  midpoints (comment added).

## Issues / flags for the reviewer

1. **Status colours as sector identity** (TickerConstellation, GlassPortfolioStack,
   sector sweep): the originals already used green/violet decoratively; I kept per-item
   variety but expressed it in tokens. Strict PATTERNS reading ("status colours never
   decorate") would drain these to an ink/blue scale - founder call if wanted.
2. **CTA visual change**: the tri-colour onboarding CTA gradient is replaced by THE
   green->blue token CTA with white label everywhere (including the carryover Save button).
   This is the single most visible change of the restyle - intentional convergence, but
   worth a founder glance.
3. **Sub-44px micro-controls remain**: per-row qty/price inputs (h-7/h-8), the min-score and
   digest-time inputs, and the +/- alert chips are dense in-card editors; wholesale height
   bumps would fight the shell's fits-viewport scroll lock. Flagged rather than changed.
4. **Focus colour stays amber** (`focus:border-accent/50`) on onboarding inputs - the literal
   token mapping of the existing behaviour. If the estate later standardises on `blue-focus`
   for focus rings (its token role), sweep this package with it.
5. `PortfolioWatchlistStep` and `AiInsightStep` are not currently mounted from
   `onboarding/page.tsx` (AiInsightStep is reused by `src/components/AiOfferCard.tsx` - its
   export/props untouched); both were converged anyway since they are in the owned list.
6. The suggestion-dropdown active row uses `bg-blue-tint` (selection semantics) instead of a
   pixel-match of the old `#151c25` grey - deliberate, matches the blue ::selection.
