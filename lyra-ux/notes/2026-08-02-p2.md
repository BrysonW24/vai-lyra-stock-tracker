## What changed

- **Canonical hexes -> Tailwind token names** everywhere (`text-[#8190a0]` -> `text-ink-3`
  etc.), reusing the P1 nearest-token ruling table verbatim for the shared legacy hexes
  (`#101720` -> `line/30`, `#17202a` track fills -> `line/70`, green borders ->
  `positive/40|50`, red sets -> `negative/50` + `negative/10`, dark ambers ->
  `accent-tint/60|80` + `accent-border/60`, `#c9d6ff`/`#f7b95e` hovers -> hover-to-bright
  `ink`, dim greys `#5f6b78 #68737f #5d6b79 #5a6470` -> `ink-dim`, `#cdd8e3` -> `ink-title`).
- **New rulings introduced by P2** (violet family - P1 never met these):
  `#a78bfa`/`#7c5cff` -> `pending`, violet chip fills `#15101f`/`#170f24` -> `pending/10`,
  violet border `#5a3b7a` -> `pending/40`. Used for: Signals panel icon, News &
  intelligence heading, PanelCarousel violet tab, CatalystRadarHelp "Attention" chip.
  Semantics check: these mark attention/hype/event surfaces, adjacent to pending's
  "in-flight" role and value-faithful to the old violet.
- **Radius convergence**: `terminal-panel ... rounded-md` -> `rounded-panel` (SignalTable,
  SignalEventsPanel, PrimeSetupsBoard, CatalystRadar, CatalystCountdown skeleton,
  TickerInsightsPanel); inner cards / stat cells / icon tiles / buttons / selects / tab
  pills `rounded`/`rounded-md` -> `rounded-cell` (drawer cards, help-drawer diagrams,
  metric cells, TickerDetail stat strip, carousel tabs + chevrons, chart toolbar buttons,
  SaveButton, PineExportButton, TickerNotScanned links). Tiny status chips (py-0.5/py-1
  text-[8-10px]) keep plain `rounded`, matching the P1 precedent.
- **tabular-nums**: added at the SignalTable section root (font-variant inherits through
  the whole table + mobile cards - the densest digit surface). CatalystCountdown segments
  already carried it; the remaining numeric surfaces are `font-mono` (inherently tabular).
- **44px mobile targets**: TickerChartView toolbar (Back / BB / RSI / MACD / Full setup)
  and PineExportButton now use the codebase's established `min-h-[44px] ... sm:min-h-0`
  pattern (HoldingsMomentumBoard toggles + selects already had it; SignalTable
  dense-toggle, explain button, mobile show-more already met 44px).
- **SignalDrawer AI narration card**: `#3a2f1d`/`#141009` -> `accent-border/60` +
  `accent-tint/60` (amber = AI-flagged content, consistent with AiGeneratedLabel accent).
- **CatalystRadar value-chain card**: `#27406b/50` border + `#0c1422` fill ->
  `blue-focus/40` + `blue-tint/60` per the P1 blue-chip ruling.
