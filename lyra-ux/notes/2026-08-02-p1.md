# P1 - Command Centre restyle (2026-08-02)

Token convergence for the Command Centre (route `/`) onto TOKENS.md v1.0.0 + PATTERNS.md.
523 hex-literal swaps across 19 owned files (RotatingFaces.tsx needed nothing - it is
layout/animation only). Zero raw hex, zero `white/`-opacity literals, zero `black/` scrims
remain in P1-owned files. `node lyra-ux/check-tokens.mjs` passes; the two tests covering
P1 components (`src/components/__tests__/product-tour.test.ts`, `tests/next-best-actions.test.ts`)
pass. No exports renamed, no props changed, no data flow altered.

## What changed

- **Every canonical hex** migrated to its Tailwind token name (`text-[#8190a0]` -> `text-ink-3`,
  `border-[#263241]` -> `border-line-strong`, etc.) in: page.tsx, CommandLayout,
  SoloCommandLayout, LocalContextBar, MetricStrip, ExecutiveStrip, MarketContextStrip,
  MacroContextStrip, IntelligenceTicker, Insight, GoalCockpit, GoalTargetEditor,
  GettingStartedBanner, SetupChecklist, ProductTour, DailyBriefCard, BriefAiNarration,
  NextBestActions, AiOfferCard.
- **ProductTour dialect migration** (was the old white/opacity dialect): `bg-black/50` scrim ->
  `bg-ground/70`; `border-white/10` -> `border-line-strong` (card) / `border-line` (dividers);
  `bg-[#0d1117]/95` -> `bg-panel-deep/95`; `rounded-2xl` -> `rounded-panel`; dots
  `bg-[#2c3a4a]` -> `bg-line-strong`; buttons onto accent/accent-tint tokens.
- **Radius convergence**: `terminal-panel ... rounded-md` -> `rounded-panel` everywhere;
  inner cards/buttons/icon tiles `rounded-md`/`rounded-lg`/`rounded-xl` -> `rounded-cell`;
  `rounded-[4px]` -> `rounded`. Tiny status chips keep `rounded`/`rounded-full` as before.
- **AiOfferCard modal**: scrim `bg-black/70` -> `bg-ground/80`, card `rounded-xl` -> `rounded-panel`.
- **GoalTargetEditor focus state**: `focus:border-[#3a4c60]` -> `focus:border-blue-focus`
  (semantic focus token; slightly more visible focus, deliberate).
