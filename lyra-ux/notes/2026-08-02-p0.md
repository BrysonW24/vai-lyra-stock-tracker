## Font decision (recorded per brief)

Removed the `font-family: Inter, ...` override from the `body` rule in `src/app/globals.css`.
Tailwind preflight applies the config's SF-first sans stack (`-apple-system, BlinkMacSystemFont,
SF Pro Text, ...` from tailwind.config.ts) to `<html>`; the body-level Inter line was silently
defeating it app-wide. No other font change. `global-error.tsx` (which renders without app CSS)
now uses an SF-first inline stack too.

## Decisions and tensions flagged for the design owner

1. **Rainbow rail (LYRA_RAMP) and bucket colour-coding kept.** They repurpose positive /
   negative-soft / pending as category colours, which sits in tension with "status colours never
   decorate". They are documented product identity ("Lyra gradient wave") and the bucket code is
   legend-like (amber = desk, green = practice), so P0 converged them to token vars rather than
   removing them. If the Lab-grade restrained look should win, flattening the ramp to ink/blue
   is a follow-up design decision, not a mechanical restyle.
2. **Focus rings converged to blue-focus** (TickerQuickSearch, PIN input, rating input) per the
   token role table; previously amber. Active-selection states stay amber.
3. **Small tap targets pre-existing, not enlarged**: DetailDrawer close (32px), HelpDrawer (20px),
   MetricHelp (16px) triggers predate this restyle; enlarging them shifts layouts across many
   surfaces, so left for a dedicated a11y pass. Shell nav controls already meet 44px.
4. **Accepted literal-colour islands** (all documented in-file): global-error.tsx (no CSS
   guaranteed), BrandLogo SVG stops (must match app-icon.svg; SVG attr), ChartPrimitives SVG
   paints (SVG attr + gradient-id URL constraint), TickerLogo/SourceFavicon hsl() hash badges +
   white contrast chips, VersionBadge light-landing variant whites, glass fallback solids in
   globals.css (#161d27/#131a23/#3c2a10 are alpha-flattened mixes with no token equivalent).
