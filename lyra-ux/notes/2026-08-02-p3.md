# P3 - Trading / Paper Bot / Plan restyle (2026-08-02)

Token convergence for the last major package onto TOKENS.md v1.0.0 + PATTERNS.md: /trading
(Bot Readiness), /trades (Trade Log), /plan (Trade Plan), /paper-bot, and the whole
src/components/paper-bot/ suite. 15 files changed (~450 line swaps); /paper (redirect only),
/plan page.tsx and /paper-bot page.tsx carried no styling; paper-bot-types.ts is types-only.
Zero raw hex, zero white/black-opacity literals, zero `rounded-md/lg/xl/2xl` remain in
P3-owned classnames. Verified: `node lyra-ux/check-tokens.mjs` OK, `npx tsc --noEmit` clean,
`npx vitest run` green for the four suites over the paper-bot logic this UI renders
(paper-bot-spine, paper-bot-commands, paper-bot-engine-path, paper-analytics - 22 tests).
No exports, props, data flow, handlers, or copy changed (diff-audited: the only non-style
delta is one trimmed trailing-whitespace line in SaaSTooltip).

## Chart/inline-style literals kept (documented in-file)

- **PaperAccountCharts** SECTOR_COLORS / POSITION_COLORS / BENCHMARK_COLORS (+ `#8190a0`
  fallback): shared between SVG `fill=`/`stroke=`/`stopColor=` attrs (var() cannot resolve
  there) and inline-style dots/bars - P2 chart-literal precedent, comment added at the
  constants. SVG text fills are byte-copies of ink/ink-dim (`#6f7d8a` converged to `#5e6b78`
  = ink-dim); baseline `#263241` = line-strong; crosshair `#5e6b78`; hover-dot ring changed
  `#040710` -> `#07090c` to match the now-`bg-ground` chart backdrop.
- **PaperAccountPanel** MiniSparkline/MiniCandlestick colour props `#43d18b`/`#ff6b6b`:
  ChartPrimitives SVG paints, byte-copies of positive/negative, gain/loss IS the meaning.
- **PaperBotQuotes** per-quote `color` values: composed with alpha suffixes (`${color}33`)
  and boxShadow strings at render time - var() cannot do that; values are byte-copies of
  blue-deep/positive/accent/pending/negative plus two decorative picks (`#e879f9`, `#ff8a5c`).
  Progress-dot inactive colour DID convert (`'#1d2733'` -> `'var(--lyra-line)'`, plain
  backgroundColor). Dead `text-white` class removed from the avatar (inline color always won).
- **PaperTickerInput** glow shadows `shadow-[0_0_24px_rgba(...)]`: alpha mixes (P0 rgba
  precedent), byte-aligned to positive/negative and the orange one re-aimed at accent
  rgba(243,163,58,...) to match the warn-collapse ruling.

  palettes and PaperBotQuotes' avatar palette repurpose status colours (and two off-palette
  hues) as categorical/decorative series - same tension P0 flagged for LYRA_RAMP and P2 for
