How the number was earned

The first run printed 2.77×. Then we attacked it.

Adversarial review dismantled the inflated number before it was reported — each fix removed a real leak. The surviving gen-1 number was smaller and true; the untouched holdout then confirmed it out-of-time.

Standing rule adopted: any lift above ~2× from this feature set triggers a mandatory leakage decomposition before the number is reported anywhere.

Where this sits — and how it climbs

Sophistication compounds: data → labels → estimator → loop

The 2026-08-01 backtest proved a better estimator on today's data buys almost nothing; better data raises the ceiling of every estimator after it. The eval discipline is already L4-grade; the estimator is L2 and the data is the binding constraint. That gap is the roadmap.

Read the numbers with these caveats

The corpus is survivor-biased — delisted names are absent, the −80% ruin class is censored, and precision here is an optimistic bound. Curated hindsight names (262 rows) were quarantined from training and headline metrics. On the option-4 label the still-listed conjunct excluded 0 winners (inert on a survivor corpus — never presented as survival discipline); the liquidity-grew conjunct excluded 457. Restated at a realistic 3% deployment base rate, top-pick precision is ≈ 6.6% — a research-queue edge, not a tradeable signal.
