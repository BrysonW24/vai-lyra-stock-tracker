First cross-generation paired test: the champion's decline is noise

Gen-2 archived per-row frozen-champion scores precisely so this test could exist. The versus-scores tool aligned the same 6,165 holdout rows across both corpora - 0 label mismatches - and paired the frozen champion's gen-3-feature scores against its gen-2-feature scores.

The apparent 1.94× → 1.69× decline is statistically nothing, exactly as the apparent gen-1 → gen-2 improvement (+0.22) was directional-only. Marginal readings moved up one generation and down the next; the paired test says the champion is statistically unchanged across three feature generations. This is a genuinely new measurement: no prior generation could run it, because gen-1 never archived per-row scores.

Rules that held across generations: the random-sample slice is always the headline · curated hindsight names never train, only disclose · >2× lift triggers a leakage decomposition (the challenger's 2.13× passed: config frozen pre-commitment, one scoring, paired nulls) · the holdout is never iterated against · a refused challenger is recorded with its numbers · the difference verdict is always the paired CI, never marginal overlap · no tier is claimed until the model beats that tier's own jumpiness sort, paired · surfacing promotion stays founder-gated on live calibration.
