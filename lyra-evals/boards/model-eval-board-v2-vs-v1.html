Why did a frozen model improve?

The champion's weights never changed between generations, so the v2 gain can only come through its inputs. The rebuild changed what its features see: quarterly-YoY fundamentals feed business quality, refreshed shares/price data feed liquidity and capital, and the two newly lit domains raise coverage completeness, which happens to carry the champion's heaviest positive weight (+0.39). No ablation has isolated the contributions yet; gen-3 will test them separately.

learned in gen 1 (deployed champion, frozen) relearned in gen 2 (challenger, refused)

Theme woke up at +0.08 and narrative (market regime) entered at −0.19: risk-on quarters were worse for finding 12-month doublers in-sample, an interaction a linear model can only average. Three domains stay honestly at zero: government, adoption, sponsorship. The sponsorship pipeline (SEC Form 4) is backfilling now. The relearned weights lost the fair fight anyway: better features beat better weights this generation.

The standing suite, unchanged and enforced

Both generations were produced by the same command family; every cycle appends to lyra-evals/model-metrics-history.jsonl with the corpus hash, so this exact v1-vs-v2 board is reconstructible from the audit trail alone.

npm run worker:emerging-winner-backtest -- build · retrain · compare · eval · holdout (one-shot) · promote · record

Rules that held across generations: the random-sample slice is always the headline · curated hindsight names never train, only disclose · >2× lift triggers a leakage decomposition · the holdout is never iterated against · a refused challenger is recorded with its numbers · surfacing promotion is founder-gated on live calibration.

Read the numbers with these caveats. The corpus is survivor-biased (delisted names absent, the ruin class censored, precision an optimistic bound) in both generations, so the v1→v2 comparison is internally fair but both absolute levels are upper bounds. The +0.22× champion delta sits inside overlapping CI90s: directional, not proven. Tier results are unstable under the market-cap recomputation and carry no conclusion yet. Holdout quarters cover one broadly favourable era; 2025Q3 matured between scorings and is included in gen-2's seven quarters. Deployment restatement at a 3% live base: ≈6.6% top-pick precision.
